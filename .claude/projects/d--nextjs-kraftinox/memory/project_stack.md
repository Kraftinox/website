- Next.js 16.1.6 (App Router, Turbopack)
- React 19.2.3
- TypeScript strict
- GSAP 3.13+ with @gsap/react
- Bootstrap 5.3
- Swiper 12
- react-hook-form 7
- react-toastify 11
- Sass/SCSS
- Single-page scroll site (no sub-pages), locales: /ro and /en

**Why:** Understanding the stack helps when suggesting compatible solutions.
**How to apply:** Use App Router patterns, avoid Pages Router conventions. Proxy (not middleware) for request interception.
